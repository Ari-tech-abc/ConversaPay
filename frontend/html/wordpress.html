CPConversaPay חזרה לדאשבורד
WORDPRESS OPERATIONS

הטמעה בלי לגעת בקוד

חברו את ConversaPay לאתר WordPress, בדקו את הווידג'ט, והחליטו בדיוק באילו עמודים הוא מופיע.

פתח הגדרות באתר
1

התקנה

העלו את תיקיית wordpress-plugin כתוסף, הפעילו אותו, ופתחו את ConversaPay Chat תחת Settings.

2

חיבור

העתיקו Business ID מהדאשבורד. הוסיפו API Key אם האתר משתמש במסלול שמחייב מפתח.

3

שליטה

בחרו כל האתר, דף הבית, או עמודים ספציפיים. אפשר גם להוסיף shortcode בתוך תוכן.

הטמעה נקודתית עם shortcode

[conversapay_chat]

בדיקת תקינות מהירה

אם הווידג'ט לא מופיע: ודאו ש-Business ID הוא UUID, שה-URL מצביע ל-ConversaPay, ושאין cache שמגיש גרסה ישנה של JavaScript.

במובייל: הווידג'ט נצמד לאזור בטוח בתחתית, החלון מקבל רוחב מלא, וכל שדה נשאר בגודל touch תקין.
