הטמעה ב־WordPress

מחברים את הצ׳אט לאתר WordPress

מתקינים את התוסף, מזינים את פרטי החיבור ובוחרים באילו עמודים הצ׳אט יופיע.

פתיחת הגדרות התוסף
1

התקנה

העלו את תיקיית wordpress-plugin כתוסף, הפעילו אותו, ופתחו את ConversaPay Chat תחת Settings.

2

חיבור

מזינים את מזהה העסק מסוג UUID ואת מפתח הווידג׳ט שיצרתם בהגדרות. הטמעה באתר זמינה במסלולי PRO ו־PREMIUM.

3

שליטה

בחרו כל האתר, דף הבית, או עמודים ספציפיים. אפשר גם להוסיף shortcode בתוך תוכן.

הטמעה נקודתית עם shortcode

[conversapay_chat]

בדיקת תקינות מהירה

אם הווידג'ט לא מופיע: ודאו ש-Business ID הוא UUID, שה-URL מצביע ל-ConversaPay, ושאין cache שמגיש גרסה ישנה של JavaScript.

בדקו גם בנייד: שהצ׳אט נפתח, שההודעות מוצגות ושהשדות וכפתור השליחה נגישים.
