3. חיבור הבוט ל-WhatsApp

מדריך זה זמין למסלול PREMIUM עם WhatsApp Business.

שלב 1 — פתח Meta / WhatsApp Cloud API צרו או פתחו אפליקציה ב-Meta for Developers והפעילו WhatsApp Business Platform.
שלב 2 — אספו 3 נתונים צריך להעתיק את Phone Number ID, את Access Token ואת Verify Token שאתם בוחרים בעצמכם.
שלב 3 — הזינו את הפרטים ב-ConversaPay בדאשבורד עברו ל-הגדרות והזינו את שלושת השדות של WhatsApp.
שלב 4 — הגדירו Webhook ב-Meta השתמשו בכתובת ה-Webhook הזאת:
https://YOUR-CONVERSAPAY-DOMAIN/api/v1/whatsapp/webhook
בשדה Verify Token ב-Meta הזינו את אותו Verify Token שהכנסתם ב-ConversaPay.
שלב 5 — בצעו בדיקה שלחו הודעת ניסיון למספר ה-WhatsApp ובדקו שההודעות נכנסות לבוט ועוברות מענה.
אם ה-Webhook מאושר אבל אין תגובה, בדקו קודם שה-Phone Number ID וה-Access Token שייכים לאותו נכס ב-Meta.
