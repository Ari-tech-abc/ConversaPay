מה פתוח בכל תוכנית?

FREE

הבסיס הנכון

ניהול מוצרים, סטטיסטיקות, פרופיל והגדרות בסיסיות.

PRO

מכירה והטמעה

דומיינים, השבתת ווידג׳ט, הזמנות, מכירות, WordPress, HTML ועד 3 API keys.

PREMIUM

הכול פתוח

כל יכולות PRO, WhatsApp, בונה אתרים AI חד-פעמי ועד 10 API keys.

1. מצא את Business ID

פתח את הדשבורד והעתק את UUID של העסק. לעולם אל תכניס service role, secret או מפתח תשלום לקוד HTML.

מפתח שמופיע בדפדפן גלוי לכל מבקר. השתמש רק ב-Business ID או ב-API key ייעודי לווידג׳ט.

2. הוסף את הווידג׳ט

החלף את שני הערכים בקוד, והכנס אותו לפני ‎</body>‎.

<script src="https://YOUR-CONVERSAPAY-DOMAIN/frontend/js/widget.js"
  data-business-id="YOUR_BUSINESS_UUID" defer></script>

הדומיין חייב להיות מורשה בתוכנית PRO או PREMIUM. FREE עובד רק באתר ConversaPay.

3. API keys

צור ונטר API keys מתוך הדשבורד. מפתח מוצג פעם אחת בלבד. המכסה היא 3 ב-PRO ו-10 ב-PREMIUM. השבתה מיידית זמינה מהדשבורד.

  1. Dashboard → API keys.
  2. צור מפתח בשם ברור.
  3. שמור אותו בכספת סודות, לא בקוד ציבורי.
  4. השבת מפתח שאינו בשימוש.

4. בדיקה

  1. רענן את האתר.
  2. ודא שכפתור הצ׳אט מופיע.
  3. שלח הודעת בדיקה.
  4. בדוק את הדומיין וה-API key בדשבורד.
