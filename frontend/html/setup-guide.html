קבל את קוד ה-API שלך

כל משתמש PRO ו-PREMIUM מקבל קוד API ייחודי. תוכל למצוא אותו בהגדרות החשבון שלך.

API Credentials
API_KEY=sk_live_1234567890abcdef
API_SECRET=sk_secret_1234567890abcdef
⚠️ שמור את קוד ה-API שלך בסוד. אל תשתף אותו עם אף אחד!
2

בחר את שיטת ההטמעה

בחר את השיטה המתאימה לאתר שלך:

התקנה ב-WordPress

אם אתה משתמש ב-WordPress, זה הכי קל:

  • עבור לתוסף שלך (Plugins)
  • חפש "ConversaPay"
  • התקן והפעל את התוסף
  • הכנס את קוד ה-API שלך בהגדרות
  • בחר את הדפים שבהם תרצה להציג את הווידג'ט
✓ זהו! הווידג'ט שלך פעיל כעת בכל הדפים שבחרת.

התקנה ב-HTML

אם אתה משתמש בקוד HTML ישיר, הוסף את השורות הבאות לפני סגירת ה-</body>:

HTML 
<!-- ConversaPay Widget -->
<script src="https://cdn.conversapay.com/widget.js"></script>
<script>
  ConversaPay.init({
    apiKey: 'sk_live_1234567890abcdef',
    position: 'bottom-right'
  });
</script>

התקנה Custom

אם אתה משתמש בפלטפורמה אחרת, אנחנו יכולים לעזור:

  • Shopify - יש לנו אפליקציה ב-App Store
  • WooCommerce - תוסף זמין
  • Webflow - קוד embed
  • Wix - אפליקציה ב-App Market
ℹ️ אם הפלטפורמה שלך לא רשומה, צור קשר עם התמיכה שלנו.
3

בדוק את ההטמעה

לאחר ההטמעה, בדוק שהווידג'ט מופיע בעמוד שלך:

  • רענן את הדף (Ctrl+F5)
  • חפש את הווידג'ט בפינת הדף
  • לחץ עליו וודא שהוא עובד
  • בדוק את הדאשבורד שלך לאישור
בעיות נפוצות

אם הווידג'ט לא מופיע:

  • וודא שהקוד הוכנס נכון בתוך </body>
  • וודא שאין חוסרים באתר שלך
  • נסה בע Lithuanian מחדש
4

הגדר את ההעדפות שלך

בדאשבורד שלך, תוכל להגדיר:

  • מיקום הווידג'ט (פינה ימנית/שמאלית)
  • צבע וסגנון
  • הודעות ברוכים הבאים
  • שיטות תשלום מקובלות
  • דומיינים מורשים
5

ניהול דומיינים

כחלק מהתוכנית שלך, תוכל להטמיע את הווידג'ט בכמה דומיינים:

  • PRO: עד 3 דומיינים
  • PREMIUM: עד 10 דומיינים

כל דומיין מקבל מגבלת קריאות API משלו. אם אתה צריך יותר, שדרג את התוכנית שלך.
