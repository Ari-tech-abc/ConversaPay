הטמעה תוך דקות

הווידג׳ט משתמש ב-business ID, לא במפתח סודי בדפדפן.

1. מצא את Business ID

פתח את הדשבורד, בחר את העסק והעתק את ה־Business ID מסוג UUID. לעולם אל תשים מפתחות service role או secret בקוד HTML.

⚠️ אין להעתיק לכאן API keys מסוג sk_live, service role או secret. קוד שמוטמע באתר גלוי לכל מבקר.

2. הוסף את הווידג׳ט

החלף את הערך ב־YOUR_BUSINESS_ID ב־UUID של העסק שלך.

<script src="https://YOUR-CONVERSAPAY-DOMAIN/frontend/js/widget.js"
        data-business-id="YOUR_BUSINESS_ID" defer></script>

הכנס את השורה לפני ‎</body>‎. הדומיין חייב להיות הדומיין שמגיש את ConversaPay בפועל.

3. בדיקה

  1. רענן את האתר.
  2. ודא שכפתור הצ׳אט מופיע.
  3. שלח הודעת בדיקה.
  4. בדוק שהדומיין מורשה בתכנית ובדשבורד.

4. בעיות נפוצות

אם הווידג׳ט לא מופיע, בדוק את ה־Business ID, את כתובת קובץ ה־JavaScript ואת הרשאות הדומיין. אין להשתמש ב־ConversaPay.init או בכתובת CDN שלא הוגדרה אצלך.
