בחרו דרך חיבור

WORDPRESS PLUGIN

חיבור דרך התוסף

התוסף מוסיף את הווידג׳ט דרך Footer, ושומר את ההגדרות ב-WordPress. נדרש WordPress 5+ ו-PHP 7.4+.

1התקינו והפעילוהעלו את תיקיית wordpress-plugin או את קובץ התוסף דרך Plugins → Add New → Upload Plugin.
2פתחו את ההגדרותעברו ל-Settings → ConversaPay Chat והדביקו Business ID. הוסיפו Widget API Key אם הדומיין חיצוני.
3בחרו איפה להציגכל האתר, דף הבית בלבד או עמודים נבחרים. שמרו ובדקו בחלון פרטי.

Shortcode לעמוד בודד

הדביקו בתוך עורך WordPress כדי לשלוט נקודתית במיקום.

[conversapay_chat]
Shortcode עוקף את כללי התצוגה הגלובליים של התוסף. אל תדביקו API Secret בקוד או בעורך התוכן.

PHP, אם אתם מטמיעים בתבנית

<?php echo do_shortcode('[conversapay_chat]'); ?>
CUSTOM HTML

קוד Script לאתר חיצוני

הדביקו את הסקריפט לפני </body>. החליפו את שני הערכים במזהה העסק ובמפתח Widget שנוצר בדאשבורד.

<script src="https://www.conversapay.org/frontend/js/widget.js"
  data-business-id="YOUR_BUSINESS_UUID"
  data-api-key="YOUR_WIDGET_API_KEY"
  data-position="bottom-right"
  data-color="#635bff"
  defer></script>
1הרשאת דומייןהוסיפו את הדומיין מתוך Dashboard → Domains. כולל www אם הוא בשימוש.
2מפתח ייעודיצרו API Key ייעודי לווידג׳ט. שמרו אותו פעם אחת, כי הוא לא יוצג שוב.
3בדיקהפתחו את האתר בחלון פרטי, פתחו את הצ׳אט ושלחו הודעת בדיקה.

הטמעה עם JavaScript config

אפשרות נוחה אם אתם טוענים את הסקריפט בצורה דינמית.

<script>
  window.ConversaPayWidgetConfig = {
    business_id: 'YOUR_BUSINESS_UUID',
    api_key: 'YOUR_WIDGET_API_KEY',
    position: 'bottom-right'
  };
</script>
<script src="https://www.conversapay.org/frontend/js/widget.js" defer></script>
BEFORE LAUNCH

Production checklist

הדברים שבאמת שוברים הטמעה כששוכחים אותם.

HTTPS פעילגם האתר המארח וגם כתובת ConversaPay חייבים להיטען ב-HTTPS.
דומיין מאומתודאו שהדומיין המדויק, כולל תת-דומיין בשימוש, מופיע ברשימת הדומיינים.
Webhook נבדקב-WhatsApp השתמשו באותו Verify Token גם ב-ConversaPay וגם ב-Meta.
CORS ו-cacheאם הקונסול מציג CORS או JavaScript ישן, נקו CDN ו-WordPress cache ובדקו שוב.
מפתחות לא נחשפיםWidget API Key יכול להיות בדפדפן, אבל Service Role, Stripe Secret ו-WhatsApp Access Token לא.

Troubleshooting

הווידג׳ט לא מופיע

בדקו Business ID בפורמט UUID, דומיין מאומת, מפתח פעיל, ושהסקריפט נטען פעם אחת בלבד.

הווידג׳ט נטען אבל אין תשובה

בדקו /health, פתחו Network ובדקו שאין 401 על Widget Key או 403 בגלל מסלול/דומיין.

WhatsApp מאומת אבל לא מגיב

בדקו Phone Number ID, Access Token ו-Verify Token. שלושתם חייבים להיות מאותו נכס Meta.

הקוד עובד בדמו ולא באתר

זו כמעט תמיד בעיית דומיין, cache או CSP. נסו חלון פרטי ובדקו את כותרות ה-Content-Security-Policy.
