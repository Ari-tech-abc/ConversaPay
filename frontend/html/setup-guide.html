1

הורד את התוסף

לחץ על הכפתור להורדת קובץ ה-PHP של התוסף. הקובץ כבר מכיל את מזהה העסק שלך.

📦

conversapay-chat.php

תוסף וורדפרס מותאם אישית עם Business ID שלך

2

העלה את התוסף לוורדפרס

יש שתי דרכים להעלות את התוסף:

דרך א׳ — דרך לוח הבקרה (קל יותר):

כנס ל-לוח הבקרה → תוספים → הוסף חדש → העלה תוסף ← בחר את הקובץ שהורדת ← לחץ "התקן עכשיו"

דרך ב׳ — דרך FTP:

העלה את הקובץ לתיקייה: /wp-content/plugins/

3

הפעל את התוסף

לאחר ההעלאה, כנס ל-לוח הבקרה → תוספים ← מצא את "ConversaPay Chat" ← לחץ "הפעל"

🎉 זהו! הצ'אטבוט יופיע אוטומטית בכל דפי האתר שלך.
4

בדוק שהכל עובד

פתח את האתר שלך בדפדפן — אמור להופיע כפתור צ'אט בפינה הימנית התחתונה.

⚠️ אם הצ'אטבוט לא מופיע — נסה לנקות את ה-Cache של וורדפרס (אם יש לך תוסף Cache כמו WP Rocket).
💡 מתאים לכל אתר — Wix, Shopify, Squarespace, HTML רגיל, ועוד
1

העתק את קוד ההטמעה

העתק את הקוד הבא והדבק אותו לפני תגית </body> בכל דף שבו תרצה שהצ'אטבוט יופיע:

2

Wix

ב-Wix Editor: לחץ על + הוסף → Embed → Custom Code

הדבק את הקוד ← בחר "Body - end" ← לחץ "Apply"

💡 ב-Wix Premium בלבד ניתן להוסיף Custom Code.
2

Shopify

כנס ל-Online Store → Themes → Edit Code

פתח את theme.liquid ← מצא את </body> ← הדבק את הקוד לפניו ← שמור

2

HTML רגיל

פתח את קובץ ה-HTML שלך ← מצא את </body> ← הדבק את הקוד ישירות לפניו:

...תוכן האתר... <script> window.ConversaPayWidgetConfig = { business_id: "YOUR_ID" }; </script> <script src="ORIGIN/frontend/js/widget.js" defer></script> </body>
