ConversaPayWidget integration demo
A plain test page

Talk to this demo.

This page exists only to test the ConversaPay chat widget. Add your business ID and widget API key in the URL, then open the chat button in the corner.

Quick setup

Open this page with your values:

/widget-demo.html?business_id=YOUR_BUSINESS_UUID&api_key=YOUR_WIDGET_API_KEY
For a real external embed, use a PRO or PREMIUM business and its active widget API key. This demo page has no extra login or app layer.

Console option:

window.ConversaPayWidgetConfig = {
  business_id: 'YOUR_BUSINESS_UUID',
  api_key: 'YOUR_WIDGET_API_KEY'
};
location.reload();
