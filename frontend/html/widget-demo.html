ConversaPayסביבת בדיקה לווידג׳ט
דף בדיקה מבודד

דברו עם הדמו.

העמוד הזה מיועד לבדוק את ווידג׳ט ConversaPay. הוסיפו את מזהה העסק ואת מפתח הווידג׳ט בכתובת, הפעילו את הווידג׳ט ובדקו את חוויית השיחה בפועל.

הגדרה מהירה

פתחו את העמוד עם הערכים שלכם:

/widget-demo.html?business_id=YOUR_BUSINESS_UUID&api_key=YOUR_WIDGET_API_KEY
להטמעה באתר אמיתי נדרש עסק במסלול PRO או PREMIUM ומפתח ווידג׳ט פעיל. הדמו הזה אינו דורש התחברות נוספת.

אפשר גם להגדיר דרך JavaScript:

window.ConversaPayWidgetConfig = {
  business_id: 'YOUR_BUSINESS_UUID',
  api_key: 'YOUR_WIDGET_API_KEY'
};
location.reload();
