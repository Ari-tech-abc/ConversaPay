# Talk2Pay Self-Service Onboarding

1. Create or confirm the business workspace.
2. Add the first product with price, currency, inventory, and a payment destination.
3. Test the AI conversation in sandbox mode.
4. Install the widget or connect WhatsApp Business.
5. Confirm webhook signatures and delivery status.
6. Run a test checkout and verify the order in the dashboard.
7. Complete business and legal details.
8. Switch to live mode only after the checklist passes.

The dashboard should show these steps as a persistent checklist, with explicit blockers for missing catalog data, missing payment configuration, and unverified webhook endpoints.
