# Talk2Pay — design proposal 02

Standalone Hebrew/RTL concept preview. Open index.html or run `node server.cjs` and visit http://127.0.0.1:4318.

Includes landing, dashboard and login views. All numbers, chat messages and orders are illustrative. No production styles, application logic, authentication or APIs are changed. Approval is required before applying this direction to the existing pages.

Direction: forest green / mint / warm white, Hebrew Rubik typography, strong hierarchy, spacious surfaces, restrained motion, visible focus, 44px controls and responsive layouts. Skill search informed the hero/features/CTA structure and accessibility guidance; the palette and Hebrew font are deliberate product-specific choices.

Revision 02 keeps the font and product copy, uses a light hero/dashboard/login canvas, adds layered conversation cards, mint highlights, orbit graphics and sculpted feature tiles. A finite, replayable conversation animation illustrates the flow; motion can be disabled and respects OS reduced-motion preferences. Changes remain isolated to this preview until the visual direction is approved.
