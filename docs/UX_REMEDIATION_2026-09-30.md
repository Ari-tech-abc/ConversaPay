# השלמת תיקוני UX — Talk2Pay

תאריך: 30 בספטמבר 2026. תיקונים בעקבות אישור המשתמש לתקן את דוח UX ולדחוף ל־main בריפו Ari-tech-abc/ConversaPay.

## טיפול בממצאים

| ממצא | התיקון |
| --- | --- |
| UX-01 | טעינת עסק שנכשלה אינה פותחת יצירת עסק. כשלי מוצרים והזמנות מציגים שגיאה וניסיון חוזר; אנליטיקה שלא נטענה אינה מוצגת כאפס. |
| UX-02 | העדפות וטופסי נתונים נעולים עד טעינה מוצלחת. כשל באזור ההגדרות מוצג עם ניסיון חוזר. ניסיון חוזר אינו דורס העדפות שכבר נטענו ונערכו. |
| UX-03 | שני מסכי הייבוא משתמשים במימוש bulk משותף. מחיר חסר/שלילי/לא מספרי נפסל; אפס מפורש מתקבל. מוצגות סיבות לפי מספר שורה, התקדמות בבאצ׳ים ותוצאות חלקיות. נדרשת הסכמה לפני יבוא הכולל שורות לא תקינות. |
| UX-04 | סימון שדות ששונו מונע דריסה על ידי תשובת onboarding מאוחרת. תשובה שמסמנת הגדרה שהושלמה אינה מפנה את המשתמש אם התחיל לערוך. |
| UX-05 | כשל בדוא״ל לאחר יצירת החשבון פותח את חלון האימות עם הסבר ושליחת קוד מחדש. |
| UX-06 | מסך התשלום מבדיל בין מזהה חסר, התחברות נדרשת, ממתין, תקלה ואישור אמיתי. מעבר להתחברות שומר את ההקשר ומחזיר אליו; יש ניסיון חוזר. פרטי Sandbox הוסרו. |
| UX-07 | תקלת שרת/רשת אינה מתוארת כסיסמה שגויה או כקישור איפוס שפג. בקשות API מוגבלות בזמן, בלי לבטל אותות ביטול של הקורא. |
| UX-08 | שמירה חסומה לפני טעינת פרופיל ועסק. אם שם העסק לא נשמר אחרי עדכון פרטי הבעלים, מוצגת הודעת תוצאה חלקית מפורשת. |
| UX-09 | בחירת קובץ היא כפתור נגיש. חלונות משתמשים בשמות נגישים, ניהול פוקוס, Tab/Escape והחזרת הפוקוס. שדה קוד ותיבות התראות קיבלו שמות נגישים. |
| UX-10 | השרת משתמש במתרגם אחיד, מילון המסכים הורחב, וטקסטים דינמיים מתעדכנים בשפה שנבחרה. נתוני משתמש וערכי שדות אינם מתורגמים. |
| UX-11 | שימוש נספר בחודש הקלנדרי הנוכחי ב־UTC עם גבול עליון ותחתון. כשל בספירה מוצג כנתון לא זמין. הכותרת מבהירה שמדובר ברשומות שימוש. |
| UX-12 | במקום מספר מכשירים מומצא מוצג המכשיר הנוכחי, עם הבהרה שרשימת מכשירים אחרים אינה זמינה. ניתוק מכשירים אחרים נשאר זמין. |
| UX-13 | הקישור נקרא ״מידע על מסמכי חיוב״, והעמוד מציין שמסמכים אינם זמינים להורדה במסך. הוסרה ההבטחה לרשימה שלא קיימת. |

בבדיקות נמצא גם ששכבת ההתראות הקודמת חסמה טפסים מאחוריה. התראות הועברו לאזור שאינו חוסם את הדף, תוך שמירת הודעה נגישה וכפתור סגירה.

## אימות

- **24 בדיקות Python**: בדיקות האבטחה הקודמות, ספירה חודשית בגבולות UTC ונתון שימוש לא זמין כשמסד הנתונים נכשל.
- **24 בדיקות UX ב־Chromium**: כשלי טעינה, שחזור העדפות, הודעות התחברות, התאוששות בהרשמה, onboarding איטי, שמירה חלקית, תשלום והקשר התחברות, מקלדת, מחיר חסר מול אפס, חיווי סשנים ומסמכים, התאמה לרוחב 375px וטקסט אנגלי גלוי בשמונה מסכים.
- **בדיקות האבטחה בדפדפן**: ייבוא ושמות API keys נשארים טקסט, וזרימת האיפוס נשארת קשורה לאסימון השחזור.
- **בדיקות PostgreSQL המקומיות**: כל שבעת קובצי ה־SQL והרשאות 27 הטבלאות ממשיכים לעבור.
- בדיקות GitHub Actions הקיימות הורצו מקומית: compileall, תחביר JavaScript, קישורי HTML וחוזה onboarding. גם git diff --check עבר.

הבדיקות המקומיות השתמשו ב־API מדומה ובמסד מבודד. לא נשלחו דוא״ל, תשלומים או בקשות נתונים למערכת הפעילה. לא בוצע מבחן שימוש עם משתמשים.

## הרצת הבדיקות

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
npm --prefix tests install
npm --prefix tests test
python -m compileall -q backend main.py scripts
python scripts/check_html_links.py
python scripts/check_onboarding_contract.py
```

נדרש Chrome מקומי, או PLAYWRIGHT_CHANNEL מתאים לדפדפן מותקן. אם Python אינו מופעל מתוך סביבת התלויות, אפשר להגדיר TEST_PYTHON לנתיב המפרש. PLAYWRIGHT_MODULE/PGLITE_MODULE מאפשרים שימוש בהתקנות קיימות.
